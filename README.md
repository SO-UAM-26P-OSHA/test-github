## Crear entorno virtual

```bash
python3 -m venv .venv
```

## Activar entorno virtual

### Linux 

```bash
source .venv/bin/activate
```



## Instalar dependencias

```bash
pip install -r requirements.txt
```

## Ejecutar FastAPI

```bash
uvicorn main:app --reloa
```
## Desactivar entorno virtual

```bash
deactivate
```
